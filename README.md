# José Menezes - Portfólio & Site Pessoal

Projeto de website responsivo, limpo e moderno desenvolvido com **HTML5, CSS3 e JavaScript puro**.

---

## 📁 Estrutura de Arquivos

```text
jose-menezes/
├── css/
│   └── style.css       # Estilos globais, variáveis CSS e responsividade
├── js/
│   └── main.js         # Menu mobile, animações de scroll e validação de formulário
├── index.html          # Estrutura principal do site
├── .gitignore          # Arquivos e pastas ignoradas pelo Git
└── README.md           # Documentação do projeto
```

---

## 🚀 Como Executar

### Opção 1: Direto no Navegador
Abra o arquivo `index.html` com um clique duplo ou arraste-o para o navegador (Chrome, Edge, Firefox, etc.).

### Opção 2: Com o VS Code (Live Server)
1. Abra a pasta `jose-menezes` no VS Code.
2. Com a extensão **Live Server** instalada, clique com o botão direito no `index.html` e selecione **Open with Live Server**.

### Opção 3: Usando Python ou Node localmente
- Com Python:
  ```bash
  python -m http.server 3000
  ```
- Com npx:
  ```bash
  npx serve .
  ```
Acesse em: `http://localhost:3000`

## 🎨 Personalização

- **Textos e Informações**: Edite o arquivo `index.html` para alterar sua biografia, projetos, links de redes sociais e contatos.
- **Cores e Tema**: Modifique as variáveis no topo de `css/style.css` (`:root`).
